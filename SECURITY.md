# Security Policy

Please report suspected security or privacy issues privately through
[GitHub Security Advisories](https://github.com/Primate411/tezos.systems/security/advisories/new)
or by email to `support@tez.capital`.

Include the affected route or file, reproduction steps, impact, and any safe
proof of concept. Please do not disclose an unpatched vulnerability publicly.
This repository is a static, client-side dashboard and does not custody keys or
funds; Tezos Systems will never ask for a seed phrase or private key.
